prevue touch --at <file>:<line>[#N] [tap|press|drag|release|long] [--no-settle]
prevue touch <x> <y> [tap|press|drag|release|long] [--no-settle]

Sends a touch to the interactive card (prevue focus <index> --on). By default it waits for animations to settle and returns the PNG.
--no-settle sends it and returns right away. settled false in the response means it didn't stop within 3 seconds (an endless animation), and the image is of that moment.

--at presses the center of the node that line drew — found in the current screen's tree (the same file:line as selection · a card's tree). A file name alone is enough.
  The response's at is the pressed node (index · of · name · bounds · point)
  #N is the Nth in the whole list inside a lazy list, otherwise the reading order
  If that line has several nodes on screen (the same line for every list item), it doesn't press and exits 2 · need:"choose" — run it again with a matches entry's at
  If it isn't on screen now, it doesn't press and exits 1 — scroll it into view with prevue scroll and run it again
<x> <y> are PNG pixel coordinates.

long is a long press — holds for the long-press time (a little over 0.5 seconds) and releases. press → release doesn't make a long press.
Send a swipe · fling as press → several drags → release — a single drag can't pass the touch slop.
Don't use it to scroll lists — prevue scroll scrolls with the wheel.
