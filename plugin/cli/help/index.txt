prevue — renders Compose @Preview without Android Studio, shows it in the browser, and redraws on save without Gradle.
Each response is one line of JSON. Details per command: prevue <command> --help

Viewing
  show <file|FQN>            opens every @Preview in that file as a viewer tab, draws the whole board, then answers with each card's PNG and tree path
  wait [file...]             waits until saved files compile and the board is redrawn — after an edit, get the result with this
  close <file|FQN>           closes a viewer tab
  previews <file>            the file's @Preview list
  board                      each card's generation, success and PNG
  card <index> [--force]     draws just one card of the board — --force redraws a card already drawn
  reload [file...]           recompiles and redraws when the watcher missed a save
  render [--fresh] [--at ms] redraws the current preview (status's preview). --at is the animation frame at that time

The same screen as the person
  selection [--ref]          where the person last pointed in the viewer — file:line and ancestor chain
  focus <index> --on|--off   turns a card interactive on and off · --size / --device change that card's screen size
  touch --at <file>:<line>   presses the node of that line on the interactive card (touch <x> <y> takes PNG pixel coordinates) · long is a long press
  scroll [<amount>]          scrolls by that many screens with the wheel · --horizontal sideways · --at the container to scroll · --until stops when the target is fully visible
  type "<text>"              types into the focused text field — press the field with touch --at first
  open                       opens the viewer in the browser again

Preparation and the daemon
  health <file>              what is missing among toolchain, dump and daemon (missing) and the next command (next)
  start --classpath <json>   starts the daemon — run the next of a health or show response as is
  setup | warmup             downloads the toolchain · takes the target repository's classpath dump (Gradle once). Needs the user's approval
  resolve <file>             health's verdict without checking whether the daemon is alive
  status · log [lines] · paths · stop [--mine|--all]

Kinds of failure (failure values) and what to do: prevue failures --help

Viewer language
  --lang <code>              the viewer language for this call (ko, en, …). Pass the conversation's language on show and open.
                             The CLI carries it into next · then, the viewer address in the response, and the address it opens in the browser

Exit codes
  0 success
  1 render or compile failure (ok:false) · some cards are images from before the save (complete:false) · waiting timed out
  2 usage · something is left to choose (need:"choose")
  3 couldn't reach the daemon · not ready yet — read missing and next in the response; if there is an ask, put it to the person as is

The repository is decided by the file path in the arguments. Commands without a file use the repository of the current directory, or failing that the running daemon if there is only one. Don't use --port.
