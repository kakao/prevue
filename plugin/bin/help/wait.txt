prevue wait [file...] [--timeout <seconds>]

Waits until the saved files compile and every card of that board is a new image, then answers in show's shape. Default 30 seconds, at most 110.
Without files, it is the current board's file. If you edited a shared component (another module), give that file — the daemon watches every module the app contains.
If an external build is updating the outputs, it waits for the new result within the time limit. stale.build.pending:true means waiting for that update; if it doesn't finish in time, it answers TIMEOUT with the reason it waited.

  exit 0   cards[]'s image · tree are the images of this save
  exit 1   read failure — COMPILE comes right away without waiting (the image is from before the save). TIMEOUT means message says what it couldn't wait for
           complete:false means the interactive card is interactive, so every other card is an image from before the save — read message
  exit 3   couldn't reach the daemon. networkBlocked:true means the daemon is alive and this shell can't reach it (don't run start)

The verdict (ok · complete · interactive · message · failure) comes first and cards last — reading just the start shows the verdict.
wait answers only for the tab being viewed (tab). To see another tab's result, show that file.
Don't guess the waiting time and read status after a sleep — you will take an old image for a new one.
