# 크기 전환 시제품

인터랙티브 크기 조절(크기 · 기기 · 접기 전환)의 모션 값을 제품 코드보다 먼저 눈으로 맞추는 정적 페이지입니다. 제품 뷰어(`plugin/viewer/`)가 아니고 데몬과 이어지지 않습니다 — 그림은 실제 nowinandroid 렌더를 담아 둔 것이고, 새 첫 장이 오는 시점은 조절기의 지연으로 흉내 냅니다.

## 띄우기

```sh
python3 -m http.server 8793 --bind 127.0.0.1 --directory prototypes/resize
```

http://127.0.0.1:8793/ 을 엽니다. 캔버스로 그림의 가장자리 색을 읽으므로 파일로 바로 열면(`file://`) 빈 자리 색이 기본값으로 돌아갑니다.

## 써 보기

아래 가운데의 크기 막대에서 고르면 그 전환이 재생됩니다. 오른쪽 조절기가 값을 바꾸고, "값 복사"가 크기 피커 UI가 그대로 쓸 JSON(스프링 매개와 CSS `linear()` 이징, 접기 곡선)을 줍니다. 만진 값은 이 브라우저에만 남고 "기본값으로"가 되돌립니다.

| 입력 | 하는 일 |
|---|---|
| 크기 막대 · `1`–`7` | `@Preview` · 320×640 · 673×841 · S26 · iPhone Duo · Fold8 · Ultra |
| 치수선 숫자 | 위는 폭, 왼쪽은 높이(dp). 누르는 순간 커스텀이 되고, Enter 나 칸을 벗어나면 바꾼다. `↑` `↓` 1dp · `⇧` 10dp 는 숫자만, `Esc` 나 바꾸지 않고 벗어나면 원래 칸으로 |
| 틀 오른쪽의 접기 · 돌리기 · 힌지 선 단추 · `F` · `O` · `H` | 기기의 접기 · 펼치기(폴더블만), 세로 ↔ 가로 돌리기, 화면 가운데 힌지 선 켜고 끄기(폴더블만) — 이 브라우저에 기억 |
| 좁은 창의 알약 | 막대가 창에 안 들어가면 알약 하나로 접힌다 — 누르면 위로 같은 칸들이 펼쳐진다 |
| `Space` | 방금 전환을 처음부터 다시 |
| `S` · 조절기의 속도 | 1× · ½ · ¼ · ⅒ — 도착 지연도 같이 느려진다 |
| `T` · 둘러보기 | 전환을 차례로 자동 재생 |
| `R` · `\` | 움직임 줄이기 · 조절기 숨기기 |

## 무엇을 흉내 내나

- **크기 막대**(사용자 grilling 2026-10-14 — 헤더 피커가 작고 다른 알약 사이에 묻혀 읽히지 않았다) — 인터랙티브 작업 공간 아래 가운데에 늘 떠 있고 한 번 눌러 바꾼다. 정해진 크기는 숫자, 크기가 아닌 것(`@Preview` · 기기)은 이름이고, 레이블 위에 크기 아이콘이 있다(grilling 2026-10-15 — 모든 아이콘이 같은 배율 891dp ≈ 18px라 모양과 상대 크기가 함께 보인다). 기기 아이콘은 두꺼운 몸체 + 가운데 힌지이고, 고른 기기는 접힘 · 돌림을 따라간다. 커스텀 칸은 없다 — 치수선에서 들어간다. 크기는 막대가 아니라 치수선이 말해서 접힌 알약에도 아이콘과 이름만 적는다. 알림 캡슐은 막대 위로 뜨고, 맞춤은 막대 몫(약 44px)만큼 아래를 더 비운다 — 아래 변의 튕김을 가리지 않는다. 헤더에는 피커가 없다.
- **치수선**(사용자 grilling 2026-10-15) — 모든 크기에 늘 있다. 틀 위에 폭, 왼쪽에 높이. 평소에는 조용한 주석(옅은 선과 회색 숫자, 선이 숫자 둘레에서 끊긴다)이고 마우스를 올리면 옅은 바탕이 생긴다. 숫자를 누르는 순간 커스텀이 된다 — 막대의 알약이 빠지고 숫자 둘이 짙은 배지가 된다(고른 표시가 막대에서 치수선으로 옮겨 온다). 바꾸지 않고 나가면 원래 칸으로 돌아가고, 바꾼 값이 숫자 칸과 같으면 그 칸이 켜진다. 이름 칸은 크기만 같아서는 켜지지 않는다(`@Preview`는 코드를 따라가고, 기기에는 접기 · 힌지가 있다). 기기에서 누르면 접기 칸은 흐려졌다가 값을 바꿀 때 걷힌다. 크기가 바뀌는 동안 치수선은 틀과 같이 움직이고 숫자는 도착 크기까지 굴러간다(튕김은 따라가지 않는다). 고치는 중에 막대를 누르면 막대가 이긴다. 끌기는 두지 않았다 — 세션을 다시 여는 지금은 놓은 뒤 새 첫 장까지 덮을 모션이 없다.
- **새로 여는 티를 숨긴다** — 전환이 시작되면 지금 그림을 멈추고(뷰어의 `freeze`), 새 첫 장이 오면 그 자리에서 바로 바꾼다. 빈칸 · 진행 표시 · LIVE 링 깜박임이 없다. 상태 알약은 도는 표시로 바뀌지 않고 도착한 시간만 고친다(1초를 넘기면 주황).
- **프리셋 · 커스텀 · 기기 전환** — 외곽선(머리카락 선)과 틀(링 · 그림자 · 그림)이 한 스프링(0.55s · 튕김 0.2)으로 같이 움직이며 한 번 가볍게 튕긴다. 따로 튕기면 사각형 둘이 엇갈려 보였다(조절기의 외곽선 튕김 · 앞섬으로 다시 갈라 볼 수 있다). 멈춘 그림은 글자 크기 그대로 왼쪽 위에 머물고 살짝 흐려진다(고정). 채우기는 글자가 확대돼 크기 변화가 아니라 줌으로 읽혔다.
- **접기 · 펼치기** — 멈춘 그림을 힌지에서 갈라 왼쪽 장이 힌지를 축으로 넘어간다. 접으면 그 뒷면이 커버 화면이 되고, 펴면 커버 화면이 표지처럼 왼쪽으로 열린다. 장의 각도와 힌지의 자리(가운데로 옮겨 가기)는 한 S자 곡선(`cubic-bezier(.42, 0, .18, 1)`, 0.6s)을 탄다 — 천천히 들고 빠르게 넘긴 뒤 부드럽게 내려놓는다. 스프링으로 돌렸을 때는 앞에서 확 넘어가고 끝에서 힌지만 혼자 미끄러졌다. 음영은 앞에서 비추는 빛(면이 돌아선 만큼 어두워진다). 치수선은 외곽선처럼 물러났다가 장이 내려앉으면 새 크기로 다시 나타난다 — 장의 가장자리를 따라가면 숫자가 933 → 466 → 475 처럼 없는 크기를 지나간다.
- **기기 화면**(grilling 2026-10-15, 사용자 지시 3차) — 기기는 Galaxy S26 · iPhone Duo · Fold8 · Fold8 Ultra다(S26 이 대중적 360×780 칸을 대신한다. iPhone Duo(Apple 사양 안 890×626 · 바깥 466×678pt, 펼치면 가로가 긴 폴더블)는 크기(pt = dp)와 몸체만 흉내 내고 그림은 같은 안드로이드 화면이다). 기기에만 화면 바깥의 짙은 몸체를 씌운다 — 기기마다 두께 · 화면 모서리 · 카메라(섬 · 펀치 홀) · 옆 단추 · 색이 다르고, 기기를 바꾸면 그 사이를 모프한다(카메라가 점에서 섬으로, 단추가 반대편으로). 실측이 아니라 다르게 보일 만큼만 추상화했다. 일반 프리뷰(@Preview · 숫자 칸 · 커스텀)의 화면은 각지다. 접기 · 돌리기 단추는 틀 오른쪽 바깥 위에 아이콘 + 글자 칸으로 세로로 있고(왼쪽 높이 치수선과 마주 본다), 기기일 때만 몸체에서 튀어나오듯 떠오른다. S26 은 돌리기만 있다. 기기를 고를 때마다 똑바로 펼친 상태부터다.
- **접힘 · 펼침 · 돌림 캐시**(사용자 지시 2026-10-15) — 제품은 모든 기기의 자세별(접힘 · 펼침 × 세로 · 가로) 그림을 미리 그려 둔다는 전제다. 접고 펴는 동안 도착 화면이 처음부터 선명하게 넘어오고, 돌릴 때는 옛 그림을 흐리지 않고 다 돌자마자 바꾼다 — 기다림이 없다(상태 알약 0.00s). 조절기에서 끄면 미리 그림이 없을 때(흐린 자리표시 → 새 첫 장)와 비교할 수 있다.
- **iPhone Duo 평면 접기**(사용자 지시 2026-10-15) — 다른 폴더블과 달리 화면 내용을 3D 로 돌리지 않는다. 넘어가는 장은 원근으로 투영한 사다리꼴(둥근 모서리)로 잘리고, 내용은 투영된 폭으로만 눌러 담는다. 끝으로 갈수록 윤곽이 내용보다 커진 자리는 어두운 유리이고, 힌지에서 멀수록 흐림(최대 × sinθ × d^1.35, 사본 다섯을 마스크로 섞는다)과 어둠이 커진다. 90° 까지는 펼친 화면의 반, 넘어서면 커버 화면이고 바닥 반은 늘 선명하다. 공개된 iPhone Duo 접기 재현들의 원리를 따라 새로 썼다. 조절기에 Duo 길이 · 흐림 · 어둠.
- **돌리기**(기기만) — 몸체(껍데기 · 틀 · 멈춘 그림)가 통째로 90° 돌아 그림이 잠깐 옆으로 눕고, 새 첫 장이 오면 똑바로 선 새 틀이 그 자리에 겹쳐 떠오른다. 곡선은 접기와 같은 S자(0.6s)이고, 넓은 펼침 화면의 대각선이 헤더 밑까지 올라가지 않게 도는 중간에만 12% 작아진다. 돌린 기기를 접으면 힌지가 가로로 누워 위 장이 아래로 넘어간다. 폰 가로는 커스텀으로 본다.
- **맞춤** — 원래 크기의 맞춤 배율을 덮어쓴 크기에도 그대로 쓰고 넘칠 때만 줄인다. 지금 뷰어처럼 크기마다 맞추면(조절기의 "고른 크기") 비율이 같은 크기 사이에서 틀은 그대로고 배율만 튀었다. 치수선 자리(위 34px · 양옆 52px)는 늘 비운다 — 숫자를 눌러 커스텀으로 들어가도 틀이 움직이지 않는 대신, 맞춤 배율이 1440×900 창에서 77% → 73%로 준다.
- **움직임 줄이기** — 자리 · 크기는 움직이지 않는다. 기다리는 동안 그림만 옅어지고 새 첫 장이 오면 새 틀이 제자리에서 겹쳐 떠오른다. 치수선도 굴러가지 않고, 새 틀이 겹쳐 떠오를 때 물러났다가 새 숫자로 나타난다.

커스텀 크기에는 렌더가 없다 — 열 수(300dp 적응 격자)가 같은 가장 가까운 렌더를 폭에 맞춰 보인다. 펼친 기기의 모서리 반경은 측정값이 없어 커버 값과 같게 둔다.

## 담긴 것

- `img/` — nowinandroid(Apache-2.0) `ForYouScreenPopulatedFeed`(phone 카드)의 실제 렌더 PNG. 이 저장소의 `plugin/bin/prevue`로 nowinandroid 체크아웃 안에서 떴다(Gradle 실행 없음, 이미 뜬 클래스패스 덤프).

  ```sh
  F=com.google.samples.apps.nowinandroid.feature.foryou.impl.ForYouScreenKt.ForYouScreenPopulatedFeed
  prevue show "$F" --index 0                                                   # original 411×891
  prevue show "$F" --index 0 --param widthDp=320 --param heightDp=640          # narrow
  prevue show "$F" --index 0 --param widthDp=360 --param heightDp=780          # popular
  prevue show "$F" --index 0 --param widthDp=673 --param heightDp=841          # foldable
  prevue show "$F" --index 0 --param device=spec:width=1248px,height=1972px,dpi=420   # fold8-cover
  prevue show "$F" --index 0 --param device=spec:width=2448px,height=1848px,dpi=420   # fold8-open
  prevue show "$F" --index 0 --param device=spec:width=1080px,height=2520px,dpi=480   # ultra-cover
  prevue show "$F" --index 0 --param device=spec:width=2256px,height=2504px,dpi=480   # ultra-open
  # 돌린 기기(-r) — 같은 spec 의 px 를 맞바꾼다
  prevue show "$F" --index 0 --param device=spec:width=1972px,height=1248px,dpi=420   # fold8-cover-r
  prevue show "$F" --index 0 --param device=spec:width=1848px,height=2448px,dpi=420   # fold8-open-r
  prevue show "$F" --index 0 --param device=spec:width=2520px,height=1080px,dpi=480   # ultra-cover-r
  prevue show "$F" --index 0 --param device=spec:width=2504px,height=2256px,dpi=480   # ultra-open-r
  # iPhone Duo — 안 2670×1878px · 바깥 1398×2034px(480dpi 로 pt = dp), 돌린 것(-r)은 맞바꾼다
  ```
